# Responsibility

Canonical rule: `7thleaf-gd/7thleaf-ops/governance/RESPONSIBILITY.md`

Local operating rule:

- READ broadly when needed.
- WRITE only within the active task / CURRENT / responsibility scope.
- Clear own-scope work proceeds without an extra gate.
- Do not overwrite another worker's CURRENT or silently take over another responsibility.
- Raise `RESPONSIBILITY_CONFLICT` only on a real collision: same branch, file, CURRENT, or responsibility.
- Unknown ownership still allows READ, investigation, and Evidence work.
- Human Gate is for irreversible, Production, safety, or genuine responsibility conflicts.

**Access broad. Context narrow. Authority narrow. Movement free.**
